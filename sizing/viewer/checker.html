Paste a model file into the box and press Check. The page runs scripts/verify-models.py in your tab, the script the build runs on the book's own models, and shows the file as the toolkit read it. The first press downloads a Python runtime, once. Nothing you paste is sent anywhere.

What it computes to

Each output is worked out with every input at its stated value or at the median of its distribution. Where an input is uncertain, the last column gives the 5th and 95th percentiles of the output.
